🚀 Kestra Hacktober 2026

Want to contribute to open source and get cool rewards while doing it? 🎁

Kestra Hacktober 2026 gives developers an opportunity to contribute to a real open-source project, improve their GitHub profile, and compete for exciting prizes.

🎁 Important: Kestra says contributors with a merged pull request can receive Kestra merchandise and goodies.

🎁 Does EVERYONE Get FREE Swags?

Short answer: Not simply by registering.

The important requirement is having a merged pull request that meets the event rules.

Think of it like this:

Register → Contribute → Get PR Merged → Get Swag 🎁

So don't register expecting automatic swag. You need to make a qualifying contribution.

🏆 What Can You Win?

Position Prize
🥇 1st Place Apple MacBook Neo
🥈 2nd Place Apple iPad 10th Generation
🥉 3rd Place $150 Amazon Gift Card

These prizes are awarded separately across the two participation tracks.

🚀 How to Participate

1️⃣ Choose Your Track

You can participate through:

  • Good-First-Issue Contributions
  • Kestra Blueprint

2️⃣ Find a Suitable Task

Choose an issue or blueprint idea that matches your skills.

3️⃣ Follow the Contribution Rules

Make sure you follow Kestra's requirements before starting your work.

4️⃣ Build & Test

Implement your solution and test it properly.

5️⃣ Submit Your Pull Request

Create your PR with all required information and screenshots.

6️⃣ Get Your PR Merged 🎯

This is the key requirement for the contributor goodies.

💻 Track 1: Good-First-Issue

Kestra provides good-first-issue tasks for contributors.

You can:

  1. Find an issue
  2. Request assignment
  3. Set up the repository
  4. Implement the solution
  5. Test your changes
  6. Add before/after screenshots
  7. Create your PR
  8. Wait for review and merging

⚠️ Don't start working on an issue before following the assignment process.

🤖 Track 2: Build a Kestra Blueprint

The second option is to create a reusable workflow.

Your blueprint needs to satisfy the event requirements, including:

  • At least 3 runnable tasks
  • At least 1 flowable task
  • At least 1 trigger
  • At least 1 non-core plugin
  • Submission through the appropriate repository
  • A successfully merged PR

📅 Important Dates

Date Event
October 1, 2026 Contributions begin
October 15, 2026 Midpoint Q&A
October 31, 2026 Final deadline
November 10, 2026 Winners announcement

⚠️ Important Rules

Before participating:

  • ❌ Don't submit meaningless changes
  • ❌ Don't submit typo-only changes
  • ❌ Don't simply copy an existing blueprint
  • ❌ Don't create unnecessary PRs
  • ✅ Follow the contribution guidelines
  • ✅ Test your changes
  • ✅ Make meaningful contributions
  • ✅ Be able to explain your work

🎯 Swag vs Prizes

These are two different things.

Reward Requirement
🎁 Kestra Merch & Goodies Eligible merged PR
💻 MacBook Neo Top contributor
📱 iPad Second place
🎁 $150 Amazon Gift Card Third place

So you don't necessarily need to win the competition to be eligible for the contributor goodies.

💡 Why Participate?

The swag is exciting, but the bigger benefit is the experience.

You can learn how to:

  • Work with a real open-source codebase
  • Use Git and GitHub
  • Create professional pull requests
  • Debug existing software
  • Read contribution guidelines
  • Communicate with maintainers
  • Build workflow automation
  • Strengthen your GitHub profile

🏁 Final Takeaway

Kestra Hacktober 2026 is more than just a swag opportunity.

It's a chance to:

LEARN → BUILD → CONTRIBUTE → GET MERGED → EARN REWARDS 🚀

And yes, the contributor goodies make the event even more interesting. 🎁

If you've been waiting for an opportunity to start contributing to open source, this could be a good time to begin.

Happy Hacking! 🚀
