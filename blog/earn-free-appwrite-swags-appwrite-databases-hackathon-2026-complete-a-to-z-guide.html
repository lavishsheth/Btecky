🗄️ Which Databases Can You Use?

Appwrite provides five database options for this hackathon.

1. TablesDB

Use structured data organized into tables, rows, columns, relationships, and indexes.

Project idea: A student task manager or inventory management system.

2. DocumentsDB

Work with flexible, document-based data structures.

Project idea: A personal knowledge base or document management application.

3. VectorsDB

Build applications that use vector embeddings and similarity search.

Project idea: An AI-powered semantic search tool or document question-answering application.

4. Managed PostgreSQL

Build relational applications using a managed PostgreSQL database.

Project idea: A job application tracker or expense management platform.

5. Managed MySQL

Use managed MySQL for applications that require a relational database.

Project idea: An online booking system or a small business management tool.

Choose the database that best fits your idea. Check the pricing details before selecting Managed PostgreSQL or Managed MySQL, as these options use dedicated infrastructure and may involve additional costs.

🏆 How Are Projects Judged?

According to the official hackathon website, submissions are evaluated using four criteria.

1. Idea and Innovation

Is your idea original? Does it solve a meaningful problem?

2. Technical Execution

Does the application work? Is it implemented properly?

3. Design and User Experience

Is the interface intuitive, accessible, and easy to use?

4. Usage of Appwrite Databases

Does your application make effective use of the database you selected?

Pro tip: Don't integrate a database just to satisfy the requirement. Make it an important part of how your application works.
