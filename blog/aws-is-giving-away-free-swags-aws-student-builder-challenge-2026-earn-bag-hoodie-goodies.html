Hey developers and students! 🚀

Amazon Web Services (AWS) is back with another exciting opportunity for student developers!

If you love participating in tech challenges, building projects, exploring cloud computing, and collecting exclusive AWS merchandise, then here's an opportunity you shouldn't miss.

AWS Student Builder Challenge 2026 – Build Your Tech Superpower is officially live on AWS Builder Center!

This time, AWS is challenging students to build and deploy their own personal portfolio website using AWS services.

And the best part?

🎁 Five winners will receive an exclusive AWS Builder Swag Bundle worth up to $300, $200 in AWS Promotional Credits, and an AWS Foundational Certification exam voucher!

Let's explore the complete details, eligibility, prizes, and participation process.

☁️ What Is AWS Student Builder Challenge 2026?

AWS Builder Center has launched an exciting student-focused hackathon called:

Build Your Tech Superpower

The challenge encourages students to build and deploy their personal portfolio websites using AWS Amplify Hosting.

But this isn't just another portfolio-building activity!

Your website should showcase your personality, technical skills, projects, achievements, and one unique interactive feature that makes your portfolio stand out.

The challenge focuses on:

  • Personal portfolio website development.
  • AWS Amplify Hosting.
  • Cloud deployment.
  • Creative web development.
  • GitHub integration.
  • Personal branding.
  • Practical AWS experience.

The goal is to create a professional portfolio that you can share with recruiters, companies, and potential employers.

💻 What Do You Need to Build?

This challenge is all about showcasing your personal and technical identity.

You need to build a personal portfolio website and deploy it using AWS Amplify Hosting.

Your portfolio must include the following sections:

1. About Me

Introduce yourself!

Share your background, interests, career goals, and what makes you unique.

2. Skills or Tech Superpowers

Showcase your technical skills, programming languages, tools, frameworks, and technologies.

For example:

  • Java
  • Python
  • JavaScript
  • React
  • AWS
  • Cloud Computing
  • AI & Machine Learning

3. Projects or Achievements

Display your best projects, hackathon experiences, technical achievements, certifications, and other accomplishments.

You can also include your GitHub repositories and project demonstrations.

4. One Creative Interactive Feature

This is where you can make your portfolio different from everyone else's!

AWS requires an original, working interactive feature that reveals something unique about you.

Here are some creative ideas:

  • 🎮 Retro Arcade Portfolio – Turn your portfolio into a mini gaming experience.
  • 🎟️ Digital Scratch Card – Let visitors reveal your hidden projects.
  • 🖥️ Windows 98 Interface – Create a nostalgic desktop-style portfolio.
  • 💻 Interactive Terminal – Allow visitors to explore your skills using commands.
  • 🎁 Virtual Fortune Cookie – Reveal your personal motto or fun facts.
  • 🎨 Dynamic Theme Switcher – Allow visitors to change your portfolio's appearance.

Remember, your creative feature must actually work, and visitors should have a visible hint showing how to discover it.

📋 How to Participate in AWS Student Builder Challenge 2026?

Follow these steps to participate.

Step 1: Visit AWS Builder Center

Open the official AWS Builder Center website and sign in using your account.

If you don't have an account, create one.

Step 2: Join the Student Builder Challenge

Visit the official hackathon page:

AWS Student Builder Challenge – Build Your Tech Superpower

Click the Join option to register for the challenge.

You must join the hackathon before submitting your project.

Step 3: Set Up Your AWS Account

Create or sign in to your AWS account.

Follow the official AWS guides to understand how to configure your development environment.

Step 4: Build Your Personal Portfolio

Create your portfolio website with all the required sections.

Make sure your website includes:

  • About Me
  • Skills or Tech Superpowers
  • Projects or Achievements
  • One working creative interactive feature

Step 5: Deploy Using AWS Amplify Hosting

Deploy your portfolio using AWS Amplify Hosting.

Your website must have a publicly accessible live URL and remain available during the judging period.

Step 6: Prepare Your GitHub Repository

Upload your project source code to GitHub.

Make sure your repository is publicly accessible and contains the required project files.

Step 7: Submit Your Project

Submit your project under the Your Project section of the official hackathon.

Your submission must include:

  1. Public portfolio website URL.
  2. GitHub repository link.
  3. Description of your creative interactive feature.
  4. Screenshots of your portfolio and AWS setup.
  5. Details of the AWS services you used.
  6. What you learned and the challenges you faced.

Make sure everything is submitted before the deadline!

👨‍🎓 Who Can Participate?

According to the official AWS challenge requirements:

  • You must be a verified student.
  • You must be at least 18 years old.
  • You need an AWS Builder Center profile.
  • Participation is individual; teams are not allowed.
  • Only one entry per person is permitted.
  • Country-specific restrictions and employee exclusions may apply.

Make sure you read the official rules before participating.

🏅 How Will AWS Select the Winners?

AWS will evaluate submissions through two rounds.

Round 1: AI and Human Scoring

All qualifying submissions will be evaluated.

The top 50 submissions will advance to the next round.

Round 2: Human Judging

A panel of AWS experts will review the shortlisted projects and select the final five winners.

Evaluation Criteria

Your project will be evaluated based on the following criteria:
