🤖 What Is the Presage SmartSpectra SDK Challenge 2026?

The Presage SmartSpectra SDK Challenge is a developer competition organized by DEV Community in collaboration with Presage.

The challenge encourages developers to build innovative applications using the Presage SmartSpectra SDK.

The SDK allows applications to capture and process real-time human signals through a camera, including:

  • Pulse.
  • Breathing rate.
  • Heart Rate Variability (HRV).
  • Facial expressions.

Your task is to build a functional application that responds meaningfully to at least one of these live signals.

The goal is to explore creative and practical applications of camera-based human sensing.

Whether you're interested in AI, health technology, productivity tools, interactive applications, or creative software, you can explore different possibilities.

🛠️ How to Participate in the DEV SDK Challenge 2026?

Follow these steps to participate.

Step 1: Visit the Official DEV Challenge Announcement

Open the official DEV Community challenge article.

Read the complete instructions, prize categories, submission requirements, and rules.

Step 2: Explore the Presage SmartSpectra SDK

Understand how the SDK captures and processes live human signals.

Check the official documentation and available examples.

Step 3: Register as a Presage Developer

Create your developer account and obtain the API key required to use the SmartSpectra SDK.

The challenge uses the Presage free trial. Additional challenge credits are not provided.

Step 4: Start Building Your Application

Build a completely new project specifically for this challenge.

Important: According to the official rules, development of your entry must begin during the challenge period, November 4–22, 2026. Simply adding SmartSpectra to an existing project that was started before the challenge does not qualify.

You can use open-source libraries, frameworks, and official starter examples.

Step 5: Integrate the SmartSpectra SDK

Your application must:

  • Integrate the Presage SmartSpectra SDK.
  • Work as a functional application.
  • Use at least one live Presage human signal.
  • Demonstrate how the signal affects the application.

Step 6: Create a Public GitHub Repository

Upload your source code to a publicly accessible repository.

Include:

  • Project description.
  • Installation instructions.
  • Setup instructions.
  • SDK integration details.
  • Required configuration information.

Step 7: Record a Demo Video

Create a demonstration video showing your application in action.

Make sure judges can clearly see the SmartSpectra integration and live human signals being used.

Step 8: Publish Your DEV Submission

Create a DEV Community post using the official submission template.

Your post must include the required hashtag:

#presagechallenge

Include your project details, repository link, setup instructions, demo video, and consent and data handling information.

Step 9: Submit Before the Deadline

Publish your submission before November 22, 2026, at 11:59 PM PST.

⚠️ Important: Consent & Data Handling

This is a particularly important part of the challenge.

Since your application works with camera-based human signals, you must clearly explain:

  • How users provide camera consent.
  • What data your application captures.
  • Whether data is stored.
  • Whether data is shared with third parties.
  • Data retention and deletion policies.
  • Whether SDK telemetry is enabled.
  • Whether optional AI services are used.
  • What information is shared with AI services.

Submissions without the required Consent and Data Handling section may be considered incomplete.

Safety restrictions: Medical diagnosis, treatment claims, medical decision-making, and covert or non-consensual monitoring are not allowed.
