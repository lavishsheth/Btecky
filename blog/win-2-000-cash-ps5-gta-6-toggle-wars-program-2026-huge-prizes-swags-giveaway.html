💻 What Is Flagsmith?

Before participating, let's understand the technology behind this hackathon.

Flagsmith is an open-source feature flag and remote configuration platform.

It allows developers to control application features without deploying new code every time they want to enable or disable something.

For example, imagine you have developed a new feature for your application.

Instead of making it available to everyone immediately, you can use Flagsmith to:

  • Enable the feature for selected users.
  • Disable features without redeploying.
  • Test different versions of a feature.
  • Gradually release new functionality.
  • Measure user engagement.
  • Compare different application experiences.

What Is Flagsmith Experimentation?

Flagsmith Experimentation helps developers perform A/B testing.

You can compare two or more versions of an application feature and measure which version performs better.

For example:

Version A: A blue Sign Up button.

Version B: A green Sign Up button.

You can divide your application traffic between these versions and measure which one generates more registrations.

Flagsmith helps analyze the experiment and identify the winning variation using its Bayesian statistical engine.

⚔️ How Does the Toggle Wars Challenge Work?

The hackathon follows a simple experimentation workflow.

Round 1: Create a Feature Flag

Create a multivariate feature flag containing the different versions you want to compare.

Round 2: Select a Metric

Choose what counts as success.

For example:

  • Button clicks.
  • User registrations.
  • Purchases.
  • Page engagement.
  • Conversion rates.

Round 3: Split Your Traffic

Decide how users should be divided between the different variations.

Round 4: Analyze and Ship the Winner

Flagsmith displays the winning probability for the different versions.

Once you identify the winner, roll it out using the same feature flag.

This is how you can use experimentation to make data-driven product decisions!
