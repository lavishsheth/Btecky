How Google Cloud Arcade points work (2026 Facilitator program)

By Lavish·18 September 2026·2 min read

If you are collecting points in the Google Cloud Arcade Facilitator program, it helps to know exactly where every point comes from. Here is the simple version.

Points from games and skill badges

  • Arcade games: each completed arcade game gives 1 point. Since April 2026 every game is worth the same single point.
  • Skill badges: every 2 skill badges give 1 point, so each badge is worth 0.5 points. Completing 18 badges is worth 9 points.

Milestone bonuses

Reaching a milestone adds a bonus on top of your game and badge points. You only receive the bonus for the milestone you reach, not for the ones before it.

The AI agent bonus

There is also a bonus milestone for an AI agent project. Earning it adds 10 points.

A worked example

Say you have completed 7 arcade games and 24 skill badges, and you have reached Milestone 1.

  • Games: 7 points
  • Skill badges: 24 x 0.5 = 12 points
  • Milestone 1 bonus: 5 points
  • Total: 24 points

The rules can change between programs, so always check the official Google Skills page for the latest details. Points shown on this website are estimates.
